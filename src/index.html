Cinco BIs operacionais da Aurora Log

A Aurora Log é uma transportadora de encomendas fictícia, com 12 centros de distribuição em 5 regionais. Cada BI responde a uma pergunta da operação — prazo de entrega, carga parada, produção, transporte e coletas — com metas, comparação com o período anterior, semáforo e filtros de período, unidade, UF/regional e cliente.

Data de referência: 31/10/2026 Histórico: 03/08/2026 a 31/10/2026 Dados fictícios

Como os dados foram feitos

Todas as bases são sintéticas, geradas por um script Python com semente fixa: 90 dias de operação, com sazonalidade por dia da semana e por hora, diferenças entre unidades e clientes e alguns ofensores claros, para que cada análise conte uma história. Nenhum dado real foi usado.

Como os números são calculados

Os 23 KPIs (K01 a K23) ficam num único módulo JavaScript de funções puras, cada um com teste de resultado conhecido. Dias úteis consideram fins de semana e feriados nacionais. Cada página traz a pergunta que responde, a data de referência e uma nota com as fórmulas.

Tecnologia

  • HTML, CSS e JavaScript puros, sem framework
  • Gráficos com Apache ECharts
  • Gerador em Python (pandas e numpy)
  • Testes com pytest, Playwright e node --test
  • Publicação estática no GitHub Pages
